# Видеоруководство «Рацион»

Версия 5 от 8 октября 2026 года: **5:28**, Full HD 1920×1080,
30 кадров в секунду, 17 глав и 72 блоков русских субтитров.

## Просмотр в сервисе

Обучение находится на **`/tutorial`** и доступно без входа. Ссылки находятся
в боковом меню и верхней панели. Страница содержит видео, главы, текст
и переключатель субтитров. Перед запуском и сборкой frontend файлы
копируются из этой папки; Docker включает их в образ сайта. Видео
раздаётся потоком с HTTP Range для перемотки.

Автономный проигрыватель — `index.html`. Для локального просмотра:

```sh
python3 docs/tutorial/serve.py
```

Откройте <http://127.0.0.1:8767/>. Готовый `ration-tutorial-ru.mp4`
можно также открыть в обычном видеопроигрывателе.

## Озвучка и монтаж

В этой версии используется готовая аудиозапись, предоставленная автором.
Уменьшен фоновый шум; обработаны короткие щелчки и резкие пики голоса.
Применены мягкая эквализация, компрессия и де-эссер.
Тихая оригинальная инструментальная музыка дополнительно приглушена
на 2 дБ под речью; начальная заставка сохранена с двухсекундным
вступлением перед началом речи.
Синтез голоса не выполнялся. Обработка и распознавание сделаны локально.
Обработка сохраняет темп речи. Задержка аудиофильтров компенсирована;
монтаж, временные метки глав и субтитров совпадают с версией 4.
Исходный файл, промежуточные дубли, запись согласия и материалы прежнего
синтеза в репозиторий не включены.

Показан реальный интерфейс с демонстрационными данными. Значения цели,
веса, фасовок и цен служат примерами.

## Файлы

- `ration-tutorial-ru.mp4` — финальное видео H.264/AAC.
- `index.html`, `poster.png` — автономный проигрыватель и обложка.
- `ration-tutorial-ru.srt`, `ration-tutorial-ru.vtt` — субтитры.
- `voiceover.txt`, `chapters.txt` — текст и метки глав.
- `video-metadata.json`, `SHA256SUMS.txt` — параметры и контрольные суммы.

Проверка после копирования:

```sh
shasum -a 256 -c SHA256SUMS.txt
```

При следующей замене озвучки необходимо обновить монтаж, главы и субтитры
по фактической длине новой дорожки. Длительность в интерфейсе берётся
из `apps/frontend/data/tutorial.json`.
