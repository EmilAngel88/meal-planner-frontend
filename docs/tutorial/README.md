# Видеоруководство «Рацион»

Готовая версия от 2 октября 2026 года: **5:49,4**, Full HD 1920×1080, 30 кадров в секунду, 17 глав и 86 блоков русских субтитров.

## Просмотр

Откройте [MP4](ration-tutorial-ru.mp4) в видеопроигрывателе или [страницу обучения](index.html) в браузере. Страница содержит переходы по главам, полный текст и переключатель субтитров; субтитры доступны и в полноэкранном режиме.

Для просмотра через локальный сервер с поддержкой перемотки запустите из корня репозитория:

```sh
python3 docs/tutorial/serve.py
```

Затем откройте <http://127.0.0.1:8767/>. Нужен только Python 3. Сервер слушает локальный адрес компьютера.

## Содержимое

- `ration-tutorial-ru.mp4` — готовое видео H.264 со звуком AAC, около 99 МиБ.
- `index.html`, `poster.png` — автономный проигрыватель и обложка.
- `ration-tutorial-ru.srt`, `ration-tutorial-ru.vtt` — субтитры для монтажа и публикации.
- `voiceover.txt` — окончательный текст для зрителя.
- `chapters.txt` — временные метки глав.
- `video-metadata.json`, `SHA256SUMS.txt` — параметры файла и контрольные суммы.

Показан реальный интерфейс с демонстрационными данными: цель, ритм питания, создание меню, состав порций, приготовление партии, ограничения повторов, история недель, закупки и календарь готовки. Значения цели, веса, фасовок и цен служат примерами.

Озвучка синтезирована локально моделью Qwen3-TTS 1.7B Base по разрешённому образцу голоса автора. Голосовой профиль OpenAI не создавался. Исходные записи, образец для синтеза, запись согласия и файлы модели в репозиторий не включены.

## Проверка готовой версии

Текст озвучки проверен локальным распознаванием речи; два сомнительных дубля заменены. Длительность аудио и видео совпадает, цифровой перегрузки нет. Проверены кадры в начале, середине и конце MP4, переходы между главами, перемотка, субтитры в обычном и полноэкранном режимах. Автоматическая проверка речи не подтверждает точность всех интонаций и сходство тембра.

После копирования или загрузки файлы можно проверить из этой папки:

```sh
shasum -a 256 -c SHA256SUMS.txt
```

При обновлении ролика пересоберите главы, субтитры и проигрыватель по фактической длительности новой озвучки, затем обновите контрольные суммы.
